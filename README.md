# Yeşim Ustası (Android)

Ham yeşim taşı alıp açtığın, ürün işleyip dükkânında sattığın çevrimdışı mobil oyun. Capacitor 8 ile Android'e paketlenir; reklamlar isteğe bağlı ödüllü AdMob reklamlarıdır.

- Oyun: `www/` (kaynak: `oyun/`, derleme: `cd oyun && python3 derle.py`)
- Android derlemesi: GitHub Actions → "Android derle" (test APK + imzalı AAB)
- Yayın adımları: [PLAY_STORE_REHBERI.md](PLAY_STORE_REHBERI.md)
- Gizlilik politikası: `docs/gizlilik.html`

Bu proje Drakun'dan bağımsızdır.
